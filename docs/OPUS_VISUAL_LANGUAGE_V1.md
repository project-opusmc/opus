# Opus Visual Language v1 — Filament / Void

Status: active Home-first direction — 2026-09-18

## Intent

Opus inherits visual DNA from SENTIA without copying SENTIA assets or turning the client into a research dashboard.

The visual grammar is:

- near-black void and large negative space;
- silver-white and cold-blue filament structures;
- sparse luminous nodes and information paths;
- orbital / aperture / vortex geometry;
- precise, quiet, research-grade presentation;
- restrained glow and strong hierarchy.

Opus is the operational expression of that language: sharper, more interactive, more compact, and always readable as a Minecraft client.

## Rules

### Void first

The canvas is near-black. Empty space is intentional. Do not fill Home with cards, statistics, marketing text, decorative widgets, or generic sci-fi chrome.

### Filament means structure

Filament is used for flow, selection, focus, relation, prediction, or activity. It is not random decoration.

Good:
- hairline silver-blue paths;
- sparse nodes;
- orbital arcs;
- edge illumination;
- subtle depth.

Bad:
- particle soup;
- neon cyberpunk;
- purple SaaS gradients;
- constant animated noise;
- random glowing curves.

### Opus mark

The Opus mark is an orbital aperture around a dark central void.

It must:
- be recognizable in monochrome;
- remain legible at small sizes;
- gain filament detail only at larger sizes;
- avoid a generic eye symbol;
- avoid a generic letter O;
- feel related to SENTIA without duplicating SENTIA identity.

### Typography

- UI: Inter.
- OPUS wordmark: uppercase, moderate weight, wide tracking.
- No futuristic display font.
- No microtext.

### Surfaces

Normal:
- black / graphite;
- thin neutral border;
- almost no bloom.

Hover / selected:
- silver-blue edge brightens;
- a short filament highlight may travel across an edge;
- interior remains dark.

### Motion

Motion is optional and quiet.

Allowed:
- line brightening;
- node resolving;
- short edge-travel highlight;
- very slow filament drift.

Forbidden:
- bounce;
- large zoom;
- constant pulsing;
- heavy particle motion.

## Home is canonical

Home is the first complete expression of this system. Keep the approved interaction hierarchy unchanged:

- account;
- Singleplayer;
- Multiplayer;
- Client Settings;
- Minecraft Settings;
- Quit.

Only after Home receives visual sign-off should this grammar propagate to the other routes.

## Home v1 target

- black void canvas;
- sparse filament field behind controls;
- new orbital Opus sigil + OPUS wordmark;
- current button geometry retained;
- buttons gain filament-edge hover treatment;
- Minecraft account remains the real skin head;
- footer remains low-emphasis.

## Anti-patterns

Do not introduce:

- glassmorphism;
- generic AI sparkle icons;
- decorative Lucide-style icon spam;
- giant rounded capsules;
- giant glowing logo;
- dashboard cards on Home;
- fake letter avatars;
- random HUD markings without information meaning.
